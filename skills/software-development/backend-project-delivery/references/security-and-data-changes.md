# 安全与数据变更

仅在用户已授权涉及权限、安全、敏感信息、Schema、迁移、回填或删除的 L3 工作时读取。

## 安全边界

- 在服务端验证身份、授权和租户边界，覆盖越权与权限撤销。
- 将外部输入视为不可信，检查注入、SSRF、路径遍历、文件上传和资源滥用。
- 减少日志、错误、追踪和导出中的凭据及敏感数据，并保留必要审计证据。
- 对支付、删除和不可逆外部操作要求与风险匹配的确认、幂等和审计。

## 数据变更

- 明确权威 Schema、消费者、兼容窗口和新旧代码共存方式。
- 优先使用 expand-contract：先扩展、再回填与校验、切换读取、最后收缩。
- 定义数据量、批次、限速、重试、断点续作和一致性校验。
- 区分真正可回滚的操作与不可逆操作；不可逆时准备备份和前滚修复方案。
- 在实施、部署或生产执行前分别确认相应授权。

## 交付门槛

报告安全假设、迁移步骤、校验结果、兼容期、监控、停止条件和恢复方案。未验证真实权限或数据行为时，不声明可发布。
