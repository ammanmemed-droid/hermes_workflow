# 服务发现变更

仅在用户已明确知道具体服务发现风险并授权相应 L3 范围，或发现信号后确认升级时读取。L1 中发现这些信号时先使用升级确认门。

## 影响范围

检查服务名、Namespace、Group、Cluster、注册方、消费者、网关或 RPC 路由、配置中心引用、部署环境和健康检查。区分仓库内可修改消费者与仓库外负责人。

## 兼容与切换

- 确认是否需要新旧名称并行注册或消费者兼容期。
- 明确注册方、消费者和网关的切换顺序。
- 定义灰度观察指标、失败阈值和停止条件。
- 确认旧名称下线条件及回滚时的注册、路由和配置恢复步骤。

## 验证

验证目标环境中的注册状态、发现结果、健康状态、关键消费者调用和失败恢复。配置文件或 Mock 测试不能证明生产服务发现可用。
